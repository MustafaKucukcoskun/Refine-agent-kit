### 2.2 Font Pairing Best Practices

**Altin Kurallar:**
1. **Basitlik kazanir** - Over-pairing bir tasarimi aninda esitir
2. **Kontrast olustur** - Display (serif) + Body (sans) veya tam tersi
3. **Ayni aile icinde kalinan pairingler** - Guvenli ama etkili (orn. Noto Sans + Noto Serif)
4. **Variable font avantaji** - Tek font ailesi icinde agirlik/genislik/optik boyut varyasyonlari

**2026 Populer Pairing Formulleri:**
```
LUKS:     Cormorant Garamond (Display) + Jost (Body)
TECH:     Space Grotesk (Display) + Inter (Body)
SAAS:     Geist (Display) + Geist Mono (Code)
YARATICI: Clash Display (Hero) + DM Sans (Body)
EDITORIAL:Playfair Display (Baslik) + Libre Baskerville (Govde)
ARTISAN:  Fraunces (Display) + Nunito (Body)
MODERN:   Plus Jakarta Sans (Display) + Satoshi (Body)
DENEYSEL: Syne (Hero) + Space Grotesk (Body)
KURUMSAL: IBM Plex Sans (Display) + Source Serif 4 (Body)
```

### 2.3 Variable Font Kullanimi

**2026 Standardi:** Google, kendi marka fontunu acik kaynak yaparak (Google Sans Flex) variable fontlari yeni standart olarak onayladi.

**Avantajlar:**
- Her breakpoint/yogunluk icin type ince ayari
- Ek karmasiklik olmadan daha cilali deneyim
- Scroll-driven `font-variation-settings` animasyonu (wght, wdth, opsz)
- Performans: tek font dosyasi vs coklu statik dosya

**Onemli Variable Fontlar:**
- Inter Variable, Roboto Flex, DM Sans Variable, Space Grotesk Variable
- Fraunces Variable (optik boyut + agirlik)
- Climate Crisis (dramatik genislik morph)

## 4. ANIMASYON VE MOTION DESIGN TRENDLERI

### 4.1 Scroll-Driven Animations

**2026 Durumu:** Artik standart beklenti. CSS Scroll-Timeline spesifikasyonu olgunlasti.

**Best Practices:**
- Ogeler fade-in, hareket veya donusum ile scroll'a bagli gorunur
- Sinematik tarama deneyimi olusturur
- `scroll-timeline` ve `view-timeline` CSS API'leri ile native destek
- Gorsel geribildirim icin section bazli renk gecisleri
- Performans: GPU-accelerated properties (transform, opacity) tercih et

**Araclar:**
- **GSAP (GreenSock):** Endustri favorisi, scroll-based motion icin robust
- **Motion (Framer Motion):** React projeleri icin deklaratif API
- **Lottie:** After Effects'ten web animasyona
- **CSS Scroll-Timeline:** Native, sifir JavaScript

### 4.2 Spring Physics vs Cubic-Bezier

| Ozellik | Spring Physics | Cubic-Bezier |
|---------|---------------|--------------|
| Dogallik | Fizik-tabanli, gercekci | Matematiksel, tahmin edilebilir |
| Kontrol | stiffness, damping, mass | x1, y1, x2, y2 |
| Duygu | Organik, canli, oyunsu | Cilali, profesyonel, kontrollü |
| Kullanim | Interaktif UI, draggable, gesture | Sayfa gecisleri, fade-in, slide |
| Araclar | Framer Motion, React Spring | CSS transitions, GSAP |
| 2026 Trendi | YUKSELISTE - tercih edilen | Hala yaygin ama ikincil |

**Tavsiye:** Mikro-etkilesimler ve interaktif ogeler icin spring; sayfa seviyesi gecisler icin cubic-bezier.

## 5. LAYOUT INNOVATION

### 5.1 Grid-Breaking Layout Teknikleri

**2026 Felsefesi:** "Tasarimcilar grid'leri nasil kullanacaklari konusunda tam yaratici ozgurluge sahip - ogeler dagılmis, yuzen veya moduler gorunebilir."

| Teknik | Aciklama | Risk | Uygun |
|--------|----------|------|-------|
| **Overlapping Content** | Z-index stacking ile ust uste binen ogeler | 3 | Yaratici ajans, moda |
| **Broken Grid** | 10-20px kasitli kayma | 4 | Deneysel, sanat |
| **Flowing S-Curve** | Seksiyonlarin dalga seklinde alternatif yonu | 3 | Startup, SaaS |
| **Collision Layout** | Ogelerin kasitli olarak catismasi | 5 | Streetwear, muzik |
| **Poster Sections** | Her viewport bir poster | 4 | Aktivizm, etkinlik |
| **Typography-as-Layout** | Harf formlari = layout | 5 | Type foundry, tasarim konferansi |

### 5.2 Bento Grid ve Alternatifleri

**2026 Durumu:** Bento grid olgunlasti - en iyi 100 SaaS urunun %67'si kullanıyor.

| Evrim Asamasi | Ozellik | Donem |
|---------------|---------|-------|
| Klasik Bento | Apple-klonu, statik moduler | 2023-2024 |
| Responsive Bento | Icerige gore uyumlu, CSS Grid tabanli | 2024-2025 |
| Animated Bento | Scroll'a tepki veren, yeniden organize olan | 2025 |

| Personalized Bento | Kullanicilarin bloklari tercihlerine gore duzenlemesi | 2026+ |

**Alternatifler:**
- **Masonry Layout** (CSS `grid-template-rows: masonry` ile native destek geliyor)

- **Timeline/Scroll Story** (dikey zaman cizgisi tabanli)

### 5.5 Scroll-Hijacking Best Practices

**NNG (Nielsen Norman Group) Tavsiyeleri:**
- Normal scroll hizi/yonunu degistirmek kullanici beklentileriyle celisir
- Islevsel degere karsi bilissel yuku tartmak gerekir
- Kullanicilar "tuzaga dusmus" hissederler

**Ne Zaman KACINILMALI:**
- Genel kamu kitlesi
- Yuksek trafik siteleri
- Coklu cihaz kullanimi
- Erisilebilirlik gereksinimleri
- Deneyimsiz kullanicilar

**Ne Zaman UYGUN:**
- Markadan yaraticilik beklenen sitelerde (sanat stuydosu, ajans)
- Sinirli alanlarda (tam sayfa degil, bolumlerde)
- Gorsel acidan zengin urun hikayelemesinde
- Tesla tarzinda: sinirli alanlarda yumusak yatay gecis

**Kaynak:** [NN/g - Scrolljacking 101](https://www.nngroup.com/articles/scrolljacking-101/) | [Digital Silk - Scrolling Effects 2026](https://www.digitalsilk.com/digital-trends/scrolling-effects/)
